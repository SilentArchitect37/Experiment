## CORE DYNAMICAL SYSTEMS EQUATION

Primary evolution equation (Cahn-Hilliard/Allen-Cahn type):
    μ_{t+1} = μ_t + g∇²μ_t - λμ_t³ + ρ(μ_t - μ_{t-1}) + η·x_t

Or in continuous form:
    dμ/dt = g∇²μ - λμ³ + ρ(μ - μ_{prev}) + η·x_t

Parameters:
    g   = Diffusion coefficient        (default: 0.1,  range: 0.05-0.3)
    λ   = Cubic nonlinearity strength  (default: 0.5,  range: 0.2-1.0)
    ρ   = Momentum coefficient         (default: 0.3,  range: 0.1-0.5)
    η   = Input coupling strength      (default: 0.05, range: 0.01-0.2)
    dt  = Time step                    (default: 0.01, range: 0.001-0.1)

Physical interpretation of terms:
    - g∇²μ:              Spatial coherence, smoothing, pattern formation
    - -λμ³:              Bistability, multiple attractors (semantic states)
    - ρ(μ-μ_prev):       Temporal memory, inertia, dialogue continuity
    - η·x_t:             Environmental coupling, listener feedback

Files:
    - recursive_engine.py:104-109    (Naive implementation)
    - advanced_engine.py:96-120      (RK4 version)
    - recursive_engine.py:226-231    (GPU version)

## ENTROPY AND EMISSION CRITERION (I² LAYER)

Recursive entropy formula:
    S_R = -k_R Σ_i μ_i² ln(μ_i² + ε)

Emission criterion:
    Emit when: |dS_R/dt| < entropy_threshold

Where dS_R/dt estimated via finite differences:
    dS_R/dt ≈ (S_R[t] - S_R[t-2]) / (2Δt)

Energy constraint:
    E = Σ_i μ_i²
    Emit only if: energy_min < E < energy_max

Files:
    - emission_detector.py:62-72     (compute_entropy)
    - emission_detector.py:83-108    (estimate_entropy_derivative)
    - emission_detector.py:110-165   (should_emit)
    - emission_detector.py:175-230   (AdaptiveEmissionDetector)

Interpretation:
    - Low dS_R/dt  → System near fixed point → Stable meaning → EMIT
    - High E       → Unstable regime → Don't emit
    - Low E        → Noise → Don't emit

## PHASE COHERENCE AND SEMANTIC GROUNDING (LoMI LAYER)

Coherence distance (Law of Mutual Identity):
    Δμ = ||μ_speaker - μ_listener||²
        = Σ_i (μ_s,i - μ_l,i)²

Alternative emission criterion:
    Emit when: Δμ reaches local minimum (mutual identity achieved)

Alignment gradient:
    ∇_μ_s Δμ = 2(μ_s - μ_l)

Can drive system toward coherence:
    dμ/dt = F(μ) - α·∇Δμ  # Added alignment force

Files:
    - dialogue_system.py:118-182     (LoMILayer)
    - emission_detector.py:233-301   (PhaseCoherenceDetector)
    - dialogue_system.py:148-157     (get_alignment_force)

Interpretation:
    - Speaker "resonates" with listener
    - Conversation as synchronization
    - Meaning = mutual phase-locking

## THREE-LAYER ARCHITECTURE

Layer 1: TDL (Trans-Dimensional Logic) - SYNTAX
    P(token_next | token_prev) = transition_matrix[token_prev, :]
    Modified logits: s'_i = s_i × P(token_i | last_token)
    Files: dialogue_system.py:53-116 (TDLLayer)
    
    Purpose: Enforce grammatical coherence

Layer 2: LoMI (Law of Mutual Identity) - SEMANTICS
    Coherence: Δμ = ||μ_speaker - μ_listener||²
    Alignment: ∇Δμ = 2(μ_speaker - μ_listener)
    Files: dialogue_system.py:118-182 (LoMILayer)
    
    Purpose: Ensure semantic coherence between agents

Layer 3: I² (Identity Squared) - RECURSIVE EMISSION
    Emit when: dS_R/dt ≈ 0 AND Δμ minimized
    Feedback: μ = μ + γ·encode(token)
    Files: dialogue_system.py:184-342 (RecursiveDialogueEngine)
    
    Purpose: Generate tokens from stability points

## NUMERICAL METHODS AND OPTIMIZATION

Integration Methods:

1. Euler (O(dt) error):
    μ_{new} = μ + dt·F(μ)
    Simple but inaccurate, requires small dt
    Files: recursive_engine.py:88-119 (NaiveEngine)

2. RK4 (O(dt⁴) error):
    k1 = F(μ)
    k2 = F(μ + dt·k1/2)
    k3 = F(μ + dt·k2/2)
    k4 = F(μ + dt·k3)
    μ_{new} = μ + dt/6·(k1 + 2k2 + 2k3 + k4)
    
    4x more accurate, 4x larger dt possible
    Files: advanced_engine.py:122-162 (RK4Engine)

3. Adaptive RK4 (Richardson extrapolation):
    μ_full = RK4_step(μ, dt)
    μ_half = RK4_step(RK4_step(μ, dt/2), dt/2)
    error = ||μ_half - μ_full||
    
    if error < tolerance:
        accept(μ_half), increase dt
    else:
        reject, decrease dt
    
    No hard clipping needed
    Files: advanced_engine.py:210-267 (AdaptiveRK4Engine)

Laplacian Computation Complexity:

    Method         Complexity  Time (512D)  Speedup
    Naive (loops)  O(n²)       ~450 μs      1.0x
    Vectorized     O(n)        ~30 μs       15x
    FFT (spectral) O(n log n)  ~15 μs       30x
    GPU (FFT)      O(n log n)  ~0.5 μs      900x

FFT-Based Spectral Laplacian (most important):
    Key: Laplacian is diagonal in Fourier space
    
    Algorithm:
        1. μ̂ = FFT[μ]           # O(n log n)
        2. L̂ = -k² ⊙ μ̂          # O(n) element-wise
        3. L = FFT⁻¹[L̂]         # O(n log n)
    
    Wavenumber array:
        k = np.fft.fftfreq(n, d=dx) × 2π
        k_squared = -(k²)
    
    Files: recursive_engine.py:160-176 (FFTEngine)
           advanced_engine.py:314-325 (FFTEngine_RK4)

## MATHEMATICAL PROPERTIES

Fixed Points / Equilibria (without external input):
    Fixed point condition: g∇²μ* - λ(μ*)³ = 0
    
    For uniform states (∇²μ = 0):
        -λ(μ*)³ = 0
        μ* ∈ {0, ±√(g/λ)}
    
    Three equilibria:
        μ* = 0              (unstable, saddle point)
        μ* = +√(g/λ)        (stable attractor)
        μ* = -√(g/λ)        (stable attractor)
    
    Interpretation: Two opposing semantic states, neutral point

Stability Analysis (linear):
    Around μ* = 0:
        dμ/dt ≈ g∇²μ
        Eigenvalues: λ_k = -g·k²
        All negative → stable (diffusion damps high frequencies)

## STATE SPACES AND FIELDS

Primary State: μ (Recursion Field)
    Type: Dense vector in ℝ^n
    Dimension: Configurable (typically 128-2048)
    Meaning: Internal semantic state / dialogue content
    Maintained: μ_t (current), μ_{t-1} (previous, for momentum)
    Files: recursive_engine.py:46-48

Secondary State: μ_listener (Listener Field)
    Type: Dense vector in ℝ^n (same dimension as μ_speaker)
    Meaning: Listener's internal state / utterance embedding
    Update: μ_listener = external_input
    Files: dialogue_system.py:129-167 (LoMILayer)

Auxiliary Fields:
    - Codebook: ℝ^(vocab_size × state_dims)
    - Energy history: [E_0, E_1, ..., E_t]

## TOKEN CODEBOOK AND DECODING

Codebook Structure:
    codebook[i] = prototype vector for token i
    Shape: (vocab_size, state_dims)
    Initialized: Random + normalized to unit vectors
    Files: dialogue_system.py:229-245

Token Decoding (μ → token):
    1. Normalize: μ_norm = μ / ||μ||
    2. Distances: dist_i = ||μ_norm - codebook[i]||²
    3. Logits: s_i = -dist_i
    4. TDL constraint: s'_i = s_i × P(i | last_token)
    5. Select: token = argmax(s')
    Files: dialogue_system.py:247-265

Token Encoding (token → μ):
    encode(token_i) = codebook[i]
    
Feedback Loop:
    feedback = encode(token) × decay_factor
    μ_{next} = μ_{current} + feedback × strength
    Files: dialogue_system.py:267-273

## EXISTING ADAPTIVE MECHANISMS

1. Adaptive Time Stepping (AdaptiveRK4Engine)
    Mathematical principle: Richardson extrapolation
    Files: advanced_engine.py:202-297
    
    Control law:
        if error < tolerance:
            dt_new = dt × (tolerance / error)^(1/5)
            dt_new = min(dt_new, dt_max)
        else:
            dt_new = dt × (tolerance / error)^(1/5)
    
    Result: Automatically prevents overflow, mean dt ~0.096

2. Adaptive Emission Threshold (AdaptiveEmissionDetector)
    Self-tuning criterion:
        adaptive_threshold = base_threshold × (1 + entropy_std)
    Files: emission_detector.py:175-230
    
    Mechanism:
        High entropy variance → raise threshold → emit less
        Low entropy variance → lower threshold → emit more

3. Soft Limiting (No Hard Clipping)
    Original: μ = clip(μ, -100, 100)  [discontinuous]
    New: μ_limited = tanh(μ / 10.0) × 10.0  [smooth saturation]
    Files: advanced_engine.py:109
    
    Properties: Linear for |μ| < 5, asymptotic to ±10

## MATHEMATICAL FLOW DIAGRAM

System State μ
    ↓
μ_{t+1} = μ_t + dt·[g∇²μ_t - λμ_t³ + ρ(μ_t - μ_{t-1}) + η·μ_listener]
    ↓
Compute Entropy: S_R = -Σ μ_i² ln(μ_i²)
    ↓
Estimate Derivative: dS_R/dt ≈ (S_t - S_{t-2})/(2Δt)
    ↓
Compute Coherence: Δμ = ||μ_speaker - μ_listener||²
    ↓
Emission Decision:
    If |dS_R/dt| < threshold AND energy_min < E < energy_max:
        token = decode(μ)
        μ = μ + γ·encode(token)  [feedback loop]
    ↓
Output: Token sequence at emission times

## COMPUTATIONAL COMPLEXITY SUMMARY

Single time step (RK4-FFT):
    - 4 FFT Laplacians: 4 × O(n log n)
    - ~80 elementwise ops: O(n)
    - Token decoding: O(vocab_size × n)
    
    Total: O(n log n) + O(vocab_size × n)
    
    For typical values (n=256, vocab=1000):
        ~1-10 ms on CPU
        ~0.01-0.1 ms on GPU (RTX 5070)

Memory:
    O(n) for state vectors
    O(vocab_size × n) for codebook
    O(vocab_size²) for transition matrix (negligible)
